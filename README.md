### 🌿 Plant Leaf Identification System

A computer vision system that classifies **32 plant species** from leaf
images using digital image processing and machine learning.

- 🔍 Extracted **shape, color, and texture features** from leaf images
- 🖼️ Applied image preprocessing using **OpenCV** and morphological techniques
- 🧠 Trained an **SVM classifier** for plant species classification
- ⚙️ Used **StandardScaler** and **GridSearchCV** for feature scaling and hyperparameter tuning
- 🎯 Achieved **90.05% classification accuracy**

**Tech:** Python • OpenCV • NumPy • Pandas • Scikit-learn • Mahotas • Matplotlib

🔗 [Repository](https://github.com/V-VINAYKUMAR/plant-leaf-identification)
